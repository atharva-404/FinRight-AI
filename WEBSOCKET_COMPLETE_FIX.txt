Cause: Not logged in, or token not stored

  1. Log out and log back in
  2. Check browser localStorage: localStorage.getItem('token')

──────────────────────────────────────
Cause: WebSocket connection not established
Solution:
  1. Check backend is running: daphne -b 0.0.0.0 -p 8000 core.asgi:application
  2. Check port 8000 is accessible
  3. Check browser console for errors
  4. Try: netstat -ano | findstr :8000 (Windows)

📊 TECHNICAL DETAILS
═══════════════════════════════════════════════════════════════════════════════════

FRONTEND: useWebSocketChat.js
────────────────────────────
How it works now:
  1. Component mounts
  2. Reads token from localStorage
  3. Builds WebSocket URL with token: ws://...?token=abc123
  4. Connects to: ws://localhost:8000/ws/ai/chat/?token=abc123
  5. Backend validates token on connection
  6. If valid: Connection accepted ✅
  7. If invalid: Connection rejected ❌

BACKEND: consumers.py
─────────────────────
Changes made:
  1. Added __init__ method:
     - Initializes self.room_group_name = None
     - Initializes self.user = None
  
  2. Updated connect() method:
     - Extracts token from query string
     - Validates token against database
     - Only sets room_group_name if authentication succeeds
  
  3. Updated disconnect() method:
     - Checks if room_group_name is set before using it
     - Prevents AttributeError if disconnect called after failed auth

Token Validation Flow:
  1. Client sends: ws://...?token=xyz123
  2. Backend extracts: token_str = "xyz123"
  3. Backend queries: Token.objects.get(key="xyz123")
  4. Backend retrieves: user = token.user
  5. Backend validates: if not user or user.is_anonymous → close(4001)
  6. Backend accepts: await self.accept()
  7. Backend sets: self.room_group_name = f"document_chat_{user.id}"
