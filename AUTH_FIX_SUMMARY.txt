   │ (No authentication)                                  │
   └─────────────────────────────────────────────────────┘

   WHAT CHANGED:
   ✓ Modified getWebSocketUrl() function
   ✓ Reads token from localStorage first
   ✓ Falls back to sessionStorage
   ✓ Includes token as query parameter: ?token=...
   
   CODE:
   ```javascript
   const token = localStorage.getItem('token') || sessionStorage.getItem('token');
   const urlParams = token ? `?token=${token}` : '';
   return `${protocol}//localhost:8000/ws/ai/chat/${urlParams}`;
   ```

2️⃣  BACKEND: backend/sockets/consumers.py
   ──────────────────────────────────────────
   
   ADDED IMPORTS:
   ✓ from django.contrib.auth.models import AnonymousUser
   ✓ from rest_framework.authtoken.models import Token
   ✓ from django.contrib.auth.models import User
   
   MODIFIED connect() METHOD:
   ✓ Extracts token from query string
   ✓ Validates token against database
   ✓ Retrieves authenticated user from token
   ✓ Rejects connection if auth fails (code 4001)
   
   FLOW:
   1. Extract: query_string → token_str
   2. Validate: Token.objects.get(key=token_str)
   3. Retrieve: token.user
   4. Accept/Reject: based on user authentication
   
   CODE:
   ```python
   if not user or user.is_anonymous:
       query_string = self.scope.get("query_string", b"").decode()
       if query_string.startswith("token="):
           token_str = query_string.replace("token=", "")
           try:
               token = await sync_to_async(Token.objects.get)(key=token_str)
               user = token.user
           except Token.DoesNotExist:
               user = AnonymousUser()
   
   if not user or user.is_anonymous:
       await self.close(code=4001)  # Auth failure
       return
   ```

CONNECTION SEQUENCE:

    1. User Logs In
       └─ Backend returns auth token (e.g., "a1b2c3d4...")
       └─ Frontend stores in localStorage
    
    2. User Navigates to Chat Page
       └─ useWebSocketChat hook initializes
       └─ Reads token from localStorage
    
    3. WebSocket Connection Attempt
       ┌─ Frontend creates: ws://localhost:8000/ws/ai/chat/?token=a1b2c3d4...
       │
       └─ Backend receives connection
          ├─ Extracts token from query string
          ├─ Validates: Token.objects.get(key="a1b2c3d4...")
          ├─ Retrieves user from token.user
          ├─ Accepts connection if user valid ✅
          └─ Rejects with code 4001 if invalid ❌
    
    4. Message Exchange
       ┌─ Frontend sends: {"question": "How are you?", "document_id": null}
       │
       └─ Backend processes
          ├─ User is already authenticated (from connect())
          ├─ Creates ChatSession with user_id
          ├─ Saves message to database
          ├─ Sends response tokens one-by-one
          └─ Frontend displays streaming response

PROBLEM: Connection closes immediately with code 4001
SOLUTION:
  1. Token is invalid or expired:
     └─ Log out and log back in
     └─ New token will be generated
  
  2. User not found in database:
     └─ Check: python manage.py shell
     └─ Run: from rest_framework.authtoken.models import Token
     └─ Run: Token.objects.all()
     └─ Token should be associated with valid user

PROBLEM: Token not found in localStorage
SOLUTION:
  1. Make sure auth system stores token in localStorage:
     └─ Check: AuthContext.js or login page code
     └─ Should have: localStorage.setItem('token', response.token)
  
  2. Check if using sessionStorage instead:
     └─ Our code checks both localStorage and sessionStorage
     └─ Either one will work

PROBLEM: Connection succeeds but still get error messages
SOLUTION:
  1. Error might be from different source:
     └─ Check backend logs for AI service errors
     └─ Check if document_id is valid (if provided)
