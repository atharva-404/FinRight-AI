🔍 DEBUGGING - If Something Goes Wrong

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Problem: "Connection Refused"
  ✓ Check: Is backend running? (daphne should output "Starting server...")
  ✓ Check: Port 8000 free? (netstat -ano | findstr :8000)
  ✓ Fix: Start backend or use different port

  Problem: "No Response from Server"
  ✓ Check: Backend logs for errors
  ✓ Try: Simpler message first ("Hello")
  ✓ Use: websocket-debug-utils.js to see message format

  Problem: "Tokens All at Once"
  ✓ Check: Browser Network → WS frames (should be multiple token messages)
  ✓ Read: WEBSOCKET_TESTING_GUIDE.md "Streaming" section

  Problem: "Mobile Doesn't Connect"
  ✓ Use: ws://YOUR-IP:8000/ws/ai/chat/ (not localhost)
  ✓ Check: CORS settings in settings.py
