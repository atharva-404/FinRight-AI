✅ FIXED: AttributeError in WebSocket disconnect

═══════════════════════════════════════════════════════════════════════════════════

PROBLEM
───────
Backend error when WebSocket connection failed authentication:

  AttributeError: 'DocumentChatConsumer' object has no attribute 'room_group_name'

When connection was rejected (WSREJECT), the disconnect() method tried to access
room_group_name which was never initialized because connect() returned early.

LOG OUTPUT:
  127.0.0.1:63664 - - [29/Nov/2025:11:44:32] "WSREJECT /ws/ai/chat/" - -
  127.0.0.1:63664 - - [29/Nov/2025:11:44:32] "WSDISCONNECT /ws/ai/chat/" - -
  AttributeError: 'DocumentChatConsumer' object has no attribute 'room_group_name'

ROOT CAUSE
──────────
1. connect() checks if user is authenticated
2. If not authenticated, it returns early with await self.close()
3. But disconnect() is still called when connection closes
4. disconnect() tried to access self.room_group_name which was never set
5. AttributeError is raised

SOLUTION
────────
Modified: backend/sockets/consumers.py

1. Added __init__ method to initialize instance variables:
   ┌─────────────────────────────────────────────────────┐
   │ def __init__(self, *args, **kwargs):               │
   │     super().__init__(*args, **kwargs)              │
   │     self.room_group_name = None                    │
   │     self.user = None                               │
   └─────────────────────────────────────────────────────┘

2. Made disconnect() safe by checking if room_group_name was set:
   ┌─────────────────────────────────────────────────────┐
   │ async def disconnect(self, code):                  │
   │     if self.room_group_name:                       │
   │         await self.channel_layer.group_discard(   │
   │             self.room_group_name,                 │
   │             self.channel_name                     │
   │         )                                          │
   └─────────────────────────────────────────────────────┘

FLOW BEFORE FIX
───────────────
connect() → Auth fails → await self.close() → return early
disconnect() called → Try to access self.room_group_name → 
❌ AttributeError: 'DocumentChatConsumer' object has no attribute 'room_group_name'

FLOW AFTER FIX
──────────────
__init__() → self.room_group_name = None ✅
connect() → Auth fails → await self.close() → return early
disconnect() called → Check if self.room_group_name → Skip discard
✅ No error, graceful cleanup
